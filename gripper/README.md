# RAF-FF Finger Attachments

This document describes how to make the food-safe finger attachments used in the RAF-FF study. The finger attachments screw on the replace the standard finger pads on a [Robotiq 2F-140 gripper](https://robotiq.com/products/adaptive-grippers#Two-Finger-Gripper).

| Part | Description |
| ---- | ---- |
| [Finger Attachment](/gripper/finger_attachment.stl) | Main "finger" which screws into the 2F-140 |
| [Smooth-Sil 940 food-grade silicon](https://www.smooth-on.com/products/smooth-sil-940/) | Food-grade silicon |
| [Finger Mold](/gripper/finger_mold.stl) | Mold which shapes the silicon around the finger |

## Instructions

1. 3D print the finger attachment and mold. We used PLA.

2. Use a Q-tip to apply a thin layer of Vaseline to the inside of the mold (this helps with removal).

3. Follow the instructions in the Smooth-Sil 940 package to prepare the silicon mixture.

4. Carefully pour the mixture into the mold. Fill the mold to about 60% capacity.

5. Slowly insert the tip of the finger attachment into the mold. Wipe away excess silicon as needed.

6. Allow molds to cure for 24 hours.

7. Slowly remove the fingers from the molds.  

8. Unscrew the default finger pads from the 2F-140 and replace with the new attachment.
